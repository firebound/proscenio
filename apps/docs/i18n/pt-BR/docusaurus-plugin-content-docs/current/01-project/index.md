# Projeto

A visão de Proscenio voltada ao desenvolvedor: como o pipeline é construído, como ele se compara a outras stacks e o que fica intencionalmente fora de escopo. Leia isto antes de mexer em qualquer coisa estrutural. A referência ativa de schema para ambos os formatos de transmissão fica ao lado desta seção, em Schema.

- [Arquitetura](01-architecture.md): os três plugins, os sistemas dentro de cada um, os dados que eles movem e onde estão a complexidade e o risco.
- [Comparação de ferramentas](03-comparison.md): como Proscenio se posiciona ao lado de outros pipelines de recorte 2D e opções nativas de engine, na forma de uma matriz de recursos.
- [Adiado](04-deferred.md): as iniciativas guarda-chuva que se encaixam conceitualmente em Proscenio, mas não estão comprometidas com um roadmap.

Para o fluxo de trabalho do artista em vez das entranhas, comece pelos [Guias](../00-guides/index.md).
