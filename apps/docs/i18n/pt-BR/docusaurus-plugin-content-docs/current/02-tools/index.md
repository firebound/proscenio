# Ferramentas

Referência de alto nível, ao nível de intenção, para cada app do pipeline. Cada ferramenta abaixo é um plugin que você instala na sua aplicação hospedeira; esta seção documenta o que cada uma faz e as superfícies que ela expõe, painel por painel.

- [Addon do Blender](blender-addon/index.md): o addon de autoria - malha, rig, pesos, slots, atlas e a exportação `.proscenio`. Referência painel a painel da barra lateral do Proscenio.
- [Plugin do Photoshop](photoshop-plugin/index.md): marque com tags e exporte um PSD em camadas para um manifesto mais PNGs, e reimporte um manifesto de volta para um PSD.
- [Plugin do Godot](godot-plugin/index.md): reimporte um `.proscenio` para uma cena nativa do Godot a cada mudança.

Para o fluxo de trabalho de ponta a ponta em vez da referência por app, comece pelos [Guias](../00-guides/index.md). Para entender como os plugins se encaixam, veja a [Arquitetura](../01-project/01-architecture.md).
