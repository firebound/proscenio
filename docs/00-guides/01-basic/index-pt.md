# Passo a passo básico

O loop completo Photoshop → Blender → Godot em uma passagem linear, agrupado pela ferramenta em que você está em cada etapa.

Para aprofundar em qualquer ferramenta específica, consulte os guias por ferramenta: [Photoshop](../02-advanced/01-photoshop.md), [Blender](../02-advanced/02-blender.md), [Godot](../02-advanced/03-godot.md).

> [!NOTE]
> **MVP em andamento.** O quickstart completo chegará com a primeira amostra de ponta a ponta. O loop abaixo descreve o fluxo quando ambos os lados estiverem prontos; alguns botões existem antes da arte de amostra.

1. [Photoshop](01-photoshop.md): crie o PSD com tags de camada, depois exporte o manifesto e os PNGs.
2. [Blender](02-blender.md): importe as camadas, construa o esqueleto, aplique o skinning nas malhas, defina os tipos de sprite, refine, adicione slots, anime, empacote o atlas e exporte.
3. [Godot](03-godot.md): solte o `.proscenio` e envolva a cena gerada.

Essa é uma passagem linear. Editar qualquer estágio e empurrar a mudança adiante de novo é [o loop de iteração](../03-iterate.md) que mantém ambos os lados em sincronia.
