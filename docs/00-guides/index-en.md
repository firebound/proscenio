# Guides

The artist-facing path through Proscenio, learned by doing. The guides run from the first install to the day-to-day iteration loop, so read them in order on your first character and dip back into the advanced pages once you know the loop.

- [Getting started](00-getting-started/index.md): prerequisites, where to get each plugin, and the shape of the end-to-end loop.
- [Basic walkthrough](01-basic/index.md): the full Photoshop -> Blender -> Godot loop in one linear pass, grouped by the tool you are in at each stage.
- [Advanced workflows](02-advanced/index.md): deeper, denser guides to each tool - the panels, the recipes, the contracts, and the gotchas.
- [Iterating through the loop](03-iterate.md): how one edit ripples across all three tools, and what is not automated yet.

For the per-app reference rather than the workflow, see the [Tools hub](../02-tools/index.md).
