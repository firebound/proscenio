# Tools

High-level, intent-level reference for each app in the pipeline. Each tool below is a plugin you install in its host application; this section documents what each one does and the surfaces it exposes, panel by panel.

- [Blender Addon](blender-addon/index.md): the authoring addon - mesh, rig, weights, slots, atlas, and the `.proscenio` export. Per-panel reference for the Proscenio sidebar.
- [Photoshop Plugin](photoshop-plugin/index.md): tag and export a layered PSD into a manifest plus PNGs, and re-import a manifest back into a PSD.
- [Godot Plugin](godot-plugin/index.md): reimport a `.proscenio` into a native Godot scene on every change.

For the end-to-end workflow rather than the per-app reference, start with the [Guides](../00-guides/index.md). For how the plugins fit together, see the [Architecture](../01-project/01-architecture.md).
