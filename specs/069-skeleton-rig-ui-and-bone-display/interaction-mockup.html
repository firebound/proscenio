Spec 069 - what to try

A. Connectivity icons - hover the chain (connected) / broken-chain (disconnected) / child-of (relative, on hand.L) icon. Connected/disconnected = info only. Relative is a live toggle: click the child-of icon on hand.L to flip it.

B. Sort - A-Z on = flat alphabetical, indent drops; off = hierarchy tree.

C. Favorites - click a star to pin; Favorites filters to pinned.

D. Rig UI - Arm.L nests IK/FK/Tweak into one labelled row. Button selects; eye toggles visibility.

E. Display As - whole-rig draw style (top of Active Armature). Native display_type.

F. Bone Display - pick a scope, pick a geometric shape, set scale/offset, Assign. Native custom_shape with Proscenio-generated primitive meshes.

G. Collection color - click a Rig UI row swatch: cycles a theme color and tints that collection's bones in the list. No native per-collection color; this batches over the bones.

Mockup only - colors/spacing approximate Blender's N-panel; real icons come from Blender's set (LINKED, UNLINKED, CON_CHILDOF, SOLO_ON/OFF, HIDE_OFF).
