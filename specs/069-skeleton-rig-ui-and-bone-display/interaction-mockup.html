Rig UI
Each row: fixed eye | the collection / subcollection select buttons (split equally and fill the row) | a fixed-width theme selector on top-level rows only. Nesting recurses: a collection with children is a header line then a row of its direct-child buttons, and each child that itself has children gets its own header row below (depth-first, no indent - the header groups it). The theme selector's three columns (dot | number | picker) are drawn on EVERY row so they line up and the buttons end at the same x; only a top-level row's picker is live and colors that whole subtree (one color control per tree). A nested row reserves the same columns with an empty dot and an inert picker. The dot is always a circle (theme color, or an empty outline), the number shows only when the subtree shares one theme. Same widgets on every row is what keeps the columns aligned - `ui_units_x` is only a minimum and cannot cap a wider widget. When the armature has no bone collections, the panel stays and shows an INFO notice pointing to Blender's Bone Collections panel rather than hiding.

Spec 069 - what to try

A. Connectivity (left icon) - every row is a bone, so the row's left icon shows connectivity (chain = connected / broken chain = disconnected / plain bone glyph for a root), not a type icon. Indicator only - the left side is never interactive. Relative parenting is a live toggle on the right (on hand.L): click to flip. Like its neighbor toggles it stays flat and shows state by swapping the icon - a filled pushpin when on (pinned to follow the parent), a hollow pushpin when off (Blender PINNED / UNPINNED) - not a near-invisible depress. Everything on the right is interactive; connect / disconnect itself stays in Blender's Edit mode.

B. Sort - A-Z on = flat alphabetical, indent drops; off = hierarchy tree.

C. Favorites - click a star to pin; Favorites filters to pinned.

D. Rig UI - nested collections recurse: arms groups arm.L / arm.R as buttons, and arm.L (which has its own children) gets its own header row below, down to fingers.L / thumb.L. Button selects; eye toggles visibility. Empty armature shows an INFO notice, not a hidden panel.

E. Display As - whole-rig draw style (top of Active Armature). Native display_type.

F. Bone Display - geometric custom shapes dropped: a flat 2D custom_shape can't orient across a 2D rig's varying bone rolls. Use Display As (E) for the bone draw style instead.

G. Collection color - the theme selector (dot | number | picker) is drawn on every row so the columns align, but only a top-level row's picker is live and colors that whole subtree (one color control per tree; nested rows reserve the columns with an empty dot + inert picker). Themed = a colored dot + theme number; no theme = an empty circle. Click the picker to cycle the theme and tint the subtree's bones in the list. No native per-collection color; this batches over the bones. The dot is a fixed-size template_node_socket drawn on every row (never a label) - identical widgets keep the column one width, since ui_units_x is only a minimum and cannot cap a wider widget.

Mockup only - colors/spacing approximate Blender's N-panel; real icons come from Blender's set (LINKED, UNLINKED, CON_CHILDOF, SOLO_ON/OFF, HIDE_OFF).
