Rig UI
Three parts per row: fixed eye | the collection / subcollection select buttons (split equally) | a fixed theme selector. The theme selector (G) shows a fixed colored dot (the theme color) + the theme number when the collection's bones share one theme, nothing when they do not; click the picker icon to recolor. (The dot is a fixed-size widget - Blender's `template_node_socket` - not a color field, which stretches and cannot be width-pinned.)

Spec 069 - what to try

A. Connectivity icons - hover the chain (connected) / broken-chain (disconnected) / child-of (relative, on hand.L) icon. Connected/disconnected = info only. Relative is a live toggle: click the child-of icon on hand.L to flip it.

B. Sort - A-Z on = flat alphabetical, indent drops; off = hierarchy tree.

C. Favorites - click a star to pin; Favorites filters to pinned.

D. Rig UI - Arm.L nests IK/FK/Tweak into one labelled row. Button selects; eye toggles visibility.

E. Display As - whole-rig draw style (top of Active Armature). Native display_type.

F. Bone Display - geometric custom shapes dropped: a flat 2D custom_shape can't orient across a 2D rig's varying bone rolls. Use Display As (E) for the bone draw style instead.

G. Collection color - the fixed theme selector at the end of each Rig UI row. Themed = a colored dot (theme color) + theme number + picker icon; no theme = a dim empty circle. Click the picker to cycle the theme and tint that collection's bones in the list. No native per-collection color; this batches over the bones. (Try Root / Leg.L / Leg.R - they start with no theme.) The colored dot is a fixed-size template_node_socket, not a color field - a color field stretches and cannot be width-pinned.

Mockup only - colors/spacing approximate Blender's N-panel; real icons come from Blender's set (LINKED, UNLINKED, CON_CHILDOF, SOLO_ON/OFF, HIDE_OFF).
