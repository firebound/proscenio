# Spec 077 TODO: Co-located multilingual docs source

Execution plan for [STUDY.md](STUDY.md). One track (docs only) with a hard ordering: build the sync tool test-first, then migrate the content it consumes, then rewire the config and verify both locales build. The Blender surface is untouched.

Language map: source suffix `-en` -> Docusaurus locale `en`, `-pt` -> `pt-BR`. English is a generated pack, not the implicit default.

## Track A - Sync tool (test-first)

### A1. Coverage guard + generation, red then green

- [ ] Add `apps/docs/scripts/sync-i18n.test.mjs` (built-in `node --test`) that drives the not-yet-written `sync-i18n.mjs` over a temporary fixture docs tree and asserts:
  - A page pair (`foo-en.md` + `foo-pt.md`) generates `i18n/en/.../current/foo.md` and `i18n/pt-BR/.../current/foo.md` with the suffix stripped and content intact.
  - The `NN-` numbered prefix survives on directories and stems (`00-guides/01-basic/01-photoshop-en.md` -> `i18n/en/.../current/00-guides/01-basic/01-photoshop.md`).
  - `docs/content/**` and `docs/images/**` are copied verbatim into BOTH locale trees (single-language assets).
  - `docs/_i18n/chrome-<lang>.json` splits into `docusaurus-theme-classic/navbar.json`, `footer.json`, and `docusaurus-plugin-content-docs/current.json` per locale; `docs/_i18n/code-pt.json` writes `i18n/pt-BR/code.json` and no `code.json` is written for `en`.
  - Coverage failure: a page missing its `-pt` sibling exits non-zero with a message naming the page; a suffix-less `.md` in a translated directory exits non-zero.
- [ ] Watch the suite fail (module missing) before writing the implementation.
- [ ] Add `apps/docs/scripts/sync-i18n.mjs`: read `docs/`, generate `apps/docs/i18n/<locale>/` for every language in the map, run the coverage guard first (fail fast), clean+rewrite each locale tree deterministically (stable ordering, no churn). A `--check` flag runs the guard without writing (for a standalone CI check if wanted).
- [ ] Watch the suite pass; output pristine.

### A2. Wire the lifecycle + test script

- [ ] Add to [apps/docs/package.json](../../apps/docs/package.json): `"prebuild": "node scripts/sync-i18n.mjs"`, `"prestart": "node scripts/sync-i18n.mjs"`, and a `"test": "node --test scripts/*.test.mjs"` (or extend an existing test script). `pnpm build` and `pnpm start` now regenerate the i18n trees automatically.

## Definition of done

- Every hand-authored page exists as `docs/<path>/<name>-en.md` + `<name>-pt.md` side by side; the pt-BR copy is the spec-072 translation verbatim.
- The Node sync tool generates both `i18n/en/` and `i18n/pt-BR/` from the co-located source, guards language coverage, and runs automatically on `pnpm build` / `pnpm start`; `apps/docs/i18n/` is gitignored and the old committed pt-BR tree is gone.
- English is a generated pack, not the implicit default: `docs.path` reads the generated English tree and the English chrome comes from `docs/_i18n/chrome-en.json`.
- `pnpm build` builds both locales clean, links and images resolve, typecheck is green, and the locale dropdown + pt-BR search work.
- The locked calls are in `decisions.md`; adding a third language is `-<lang>` files + a chrome file + one map row.
