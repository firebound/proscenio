# Duplication (DRY)

Genuine copy-pasted/near-identical logic confirmed by reading the actual function bodies (token-level, not name matching). Phase 1's name-based digest found only 2 clusters; the phase-2 body-comparison sweep found **13 more**. The biggest concentration is the Godot writer (three independent re-derivations of the same 2D-rotate, action-length, and image-path math) and the automesh/skinning modal sessions.

## High

- **automesh-modal-preamble** `[high]` - [automesh_authoring.py:222,230-249](../../../apps/blender/operators/automesh/automesh_authoring.py#L222) + [draw_mesh_vertices.py:89,97-119](../../../apps/blender/operators/automesh/draw_mesh_vertices.py#L89) - the two Automesh authoring modals share a line-for-line identical `poll` (active-object mesh check, `other_running` exclusivity, `first_material_image` check) and an invoke preamble with the same three guard blocks and the exact same multi-line warn/error report strings. Fix: extract `poll_mesh_with_image(context)` and `validate_authoring_invoke(operator, context) -> Image | None` into a shared `automesh/_authoring_preconditions.py`; both operators delegate.
