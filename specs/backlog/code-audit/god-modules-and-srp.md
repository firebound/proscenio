# God modules, god functions, and single-responsibility

Oversized modules/functions and cohesion splits. All verified against the real code. Every one is **low severity** - these are maintainability/cohesion refinements, not bugs. Several phase-1 claims were corrected on verification (line counts, what is already extracted, whether the split is worth it); those are marked `[adjusted]`. Defer the large ones until the file is being touched for another reason.

See also the two refuted SRP claims in [refuted.md](refuted.md) (`apply-atlas-snapshot`, `slot-attachment-keyframe`).

## God modules / functions

- **automesh-authoring-operator** `[low/large]` `[confirmed]` - [automesh_authoring.py](../../../apps/blender/operators/automesh/automesh_authoring.py) - ~1556-line modal operator concentrates the stage state machine, three pen/stroke sub-machines, vert snapping, axis-lock, delete-hover hit-testing, and per-stage overlay plumbing in one class. Fix: continue the `VertexPen` extraction - pull the open-stroke click-pen state machine into a pen-controller, move delete-hover hit-testing into a pick/hover helper, leave the operator as stage-navigation + event dispatch.
- **quick-armature-operator** `[low/large]` `[adjusted]` - [quick_armature.py:87](../../../apps/blender/operators/armature/quick_armature.py#L87) - ~865-line class (not 985) with ~30 modal-state fields conflating modal SM, bone CRUD, in-modal undo/redo, view + selection snapshot/restore, armature creation, draw-handler lifecycle. Correction: math + event classification are already extracted - do not re-extract. Fix: extract the stateful concerns into delegate objects - `ViewSnapshot`, `SelectionSnapshot`, `BoneSession` (records + create/undo/redo), `HandlerLifecycle` - leaving a thin operator shell.
- **photoshop-planes-module** `[low/medium]` `[confirmed]` - [planes.py](../../../apps/blender/importers/photoshop/planes.py) - 585-line module concentrates placement math, mesh reuse/rebuild, weight reproject, EEVEE material graph, collection relinking, and 5 custom-property taggers behind two `stamp_*` entry points. Fix: split into `placement.py` / `mesh_build.py` / `material.py` / `tags.py`; keep planes.py as the thin orchestrator. All helpers are module-private, so the split is internal-only. (Overlaps `planes-placement-math` in [misplaced-code.md](misplaced-code.md).)
- **panels-skeleton** `[low/small]` `[confirmed]` - [skeleton.py](../../../apps/blender/panels/skeleton.py) - 853-line module concentrates a bone UIList, 6 panels, a self-contained IK helper cluster (584-663), and Rig UI theme-swatch rendering (60-94 + 520-581), against the panels/ `_draw_*.py` split convention. Fix: extract IK helpers to `_draw_ik.py` and swatches to `_draw_rig_ui.py`; re-export `_active_ik_constraint` so test_ik_authoring_ergonomics.py:72 still resolves.
- **skinning-props-pg** `[low/medium]` `[confirmed]` - [scene_props.py:70](../../../apps/blender/properties/scene_props.py#L70) - `ProscenioSkinningProps` (328 lines) is one flat PropertyGroup mixing automesh / bind / weight-transfer / edit-weights / authoring-modal / debug knobs. Fix: split into nested PropertyGroups (`AutomeshProps`/`BindProps`/`AuthoringProps`/`DebugProps`). **Breaking:** every `.skinning.<field>` site across ~47 files plus bl_rna string lookups and the authoring_stages snapshot dataclass must be updated - do it as a mechanical rename with the test gate green.
- **help-topics-module** `[low/small]` `[confirmed]` - [help_topics.py:124](../../../apps/blender/core/help_topics.py#L124) - 699-line module bundles render model/reflow, a ~487-line static `HELP_TOPICS` table, and the `_DOC_PATHS` map + `topic_for` dispatch. Low priority; the module is cohesive and heavily documented.
- **godot-export-orchestration** `[low/small]` `[confirmed]` - [writer/__init__.py:116](../../../apps/blender/exporters/godot/writer/__init__.py#L116) - `export()` interleaves orchestration with two independent bpy state-restore concerns (rest-pose detach + matrix_basis zeroing; hidden-object unhide) in one inline try/finally, plus a mid-function `mathutils` import. - **create-slot-execute** `[low/small]` `[confirmed]` - [slot/create.py:69](../../../apps/blender/operators/slot/create.py#L69) - 55-line `execute` inlines Empty construction, two divergent anchoring branches (bone bind vs seed center), flagging, attachment, selection, dual reporting. - **operators-selection** `[low/small]` `[adjusted]` - [selection.py](../../../apps/blender/operators/selection.py) - 506-line module bundles 9 operators spanning object/bone selection, action assignment, favorites, per-bone toggles. - **authoring-ik-module** `[low/small]` `[adjusted]` - [authoring_ik.py](../../../apps/blender/operators/armature/authoring_ik.py) - correction: this is a 416-line single-feature (Proscenio IK chain) module with four cohesive operators sharing helpers - a size-only smell, not an "unrelated bundle". Fix (if trimming): extract only the shared low-level helpers into a private `_ik_chain.py`; do NOT split by operator (that fractures the shared helpers). Lower priority.
- **create-driver-execute** `[low/small]` `[adjusted]` - [driver.py:185](../../../apps/blender/operators/driver.py#L185) - ~88-line `execute` bundles validation, idprop seeding, fcurve creation, expression selection, driver/target/transform config, PG mirror-back. - **build-automesh-debug-stages** `[low/medium]` `[adjusted]` - [bridge.py:744](../../../apps/blender/core/bpy_helpers/automesh/bridge.py#L744) - correction: `build_automesh` interleaves 6 (not 9) debug-stage early-returns; each snapshots an intermediate only available at that point. - **bpy-compat-shims** `[low/trivial]` `[adjusted]` `[quick win]` - [_bpy_compat.py](../../../apps/blender/core/bpy_helpers/_shared/_bpy_compat.py) - correction: the flat module is correctly placed as the documented shim home (32 shims) - keep it, no split. ## Single-responsibility

- **atlas-paths-mixed** `[low/small]` `[confirmed]` - [atlas_pack/_paths.py](../../../apps/blender/operators/atlas_pack/_paths.py) - `_paths.py` is a grab-bag mixing path derivation, UV-layer snapshotting, and material image query/mutation (its own docstring concedes the mix). Fix: keep `packed_atlas_paths` in `_paths.py`, move snapshot helpers to `_snapshot.py`, move material helpers to `_materials.py`; update 3 import sites. Coordinate with spec 062 TODO touching L64.
- **props-access-armature** `[low/small]` `[confirmed]` - [props_access.py:29](../../../apps/blender/core/_shared/props_access.py#L29) - mixes generic PropertyGroup None-guard accessors with a self-contained armature-resolution policy (5 functions, distinct consumers). Fix: extract `active_armature`/`resolve_target_armature`/`resolve_export_armature`/`_picked_scene_armature`/`describe_export_target` into `core/_shared/armature_resolve.py`; update ~8 importers + test + the sonar ignore key. Pure move, no behavior change.
- **eval-frame-sandbox** `[low/small]` `[adjusted]` - [sprite_frame_animations.py:134](../../../apps/blender/exporters/godot/writer/sprite_frame_animations.py#L134) - `_eval_frame` evals a .blend-authored driver expression in a hand-rolled, untested restricted-eval namespace, duplicated across two sites. **Important correction to phase 1: this is NOT an external attacker-controllable RCE** - in a build-time tool a hostile .blend already has arbitrary-execution paths. The value is correctness + consolidation + test coverage, not closing an attack surface. Fix: extract the restricted eval into one shared helper (consolidating both sites) and unit-test it (math/var resolves; name errors / disallowed builtins -> None; non-numeric rejected).
- **place-and-tag-hidden-dep** `[low/small]` `[adjusted]` - [planes.py:112](../../../apps/blender/importers/photoshop/planes.py#L112) - `_place_and_tag` self-resolves `y_location_spacing` via a function-local `addon_prefs` import + `bpy.context`. Correction: the local import is also a register-cycle workaround, not purely a hidden dependency. Fix: thread `spacing: float` down from the orchestrator (resolve once in import_psd/reimport_element, pass through to `_layer_placement` which already accepts it) - removes both the local import and the context reach-in without re-introducing the register cycle.
- **cdt-inputs-passthrough** `[low/trivial]` `[adjusted]` `[quick win]` - [authoring_pipeline.py:347](../../../apps/blender/core/bpy_helpers/automesh/authoring_pipeline.py#L347) - `_build_stroke_cdt_inputs` is a thin single-use adapter over `_strokes_to_cdt_inputs` (concatenates two stroke lists, unpacks two fields, pins two args to None); called once at line 525 (not 535). Fix: inline at the call site and delete the wrapper; carry the concatenation rationale as a comment if worth keeping.
